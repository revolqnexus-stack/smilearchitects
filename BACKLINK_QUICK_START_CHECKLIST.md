## TROUBLESHOOTING

**Problem:** No responses to media pitches
- **Solution:** Make story more newsworthy (conduct notable camp first, then pitch the story after)

**Problem:** Schools not responding
- **Solution:** Follow up by phone, visit in person, get introduction from parent/board member

**Problem:** Links not getting indexed
- **Solution:** Wait 2-4 weeks, submit URLs to Google Search Console, ensure linked page is crawlable

**Problem:** Acquired link but it's nofollow
- **Solution:** That's okay! Nofollow links from relevant, authoritative sources still have value. Don't obsess over dofollow vs nofollow.

**Problem:** Competitor has links from X website
- **Solution:** Research if that opportunity is still available. If yes, pursue it. If no, find similar opportunities.
